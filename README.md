>该仓库为迷你世界UGC编译器的所有函数查询 只有函数名 没有调用与传参方式

 
# 项目说明
 
迷你世界的Lua脚本引擎将API划分为引擎内部接口与开发者公开接口两部分。官方编辑器仅开放 devServices 内的接口，大量存在于 services 表中的引擎原生函数，会通过标记、禁用列表、调用冷却、运行环境限制等方式对普通脚本做访问拦截。
开发者可以从中调用些有帮助的接口 例如**Player:RefreshItemTips** 修改道具介绍
 
 
# 仓库内容
 
1. 接口库.lua：包含 devServices 、 services 、 dismethods 、 ScriptFenvG 全部数据表，以及API模式、返回类型、运行环境枚举定义。
 
# 关键标记说明
 
- devServices：开发者公开接口，普通地图脚本可直接调用
- services：引擎原生接口，不在公开列表时存在调用限制
- LuaApi3_InternalApi：引擎内部接口，普通脚本权限不足无法调用
- dismethods：禁用接口，任何情况下调用直接失败
- [2] = {秒数, 提示}：接口调用冷却频率限制
- envType：接口运行环境约束（主机、客户端、运动环境）
- ScriptFenvG：脚本全局环境白名单，控制可用全局变量与基础库
 
# 使用方式
 
1. 查阅 查看说明.md ，阅读接口判断逻辑。
2. 在 接口库.lua 检索目标函数，对照标记判断可用性。
3. 结合文档案例，确认接口是否存在冷却、环境、特殊脚本文件等前置条件。
 
注意：标记为内部、禁用、特殊脚本限定的接口，即使配置表内存在，在正式迷你世界运行环境中依旧无法调用，需要特殊脚本文件 他需要包括特殊权限才行
